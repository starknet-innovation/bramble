# @bramble/testkit

Shared deterministic fixtures for the KMS, Ledger management and the side panel.

- **Layer:** `testing`. See [Modular architecture](../../../docs/MODULAR_ARCHITECTURE.md#package-responsibilities) for what each layer may depend on.
- **Entry points:** `@bramble/testkit/avnu-route`, `@bramble/testkit/fake-kms`, `@bramble/testkit/ledger-management`, `@bramble/testkit/sidepanel`.
- **Boundary:** Development only. Forbidden from every extension production bundle.

Run `bun run check` in this directory for its type check.
