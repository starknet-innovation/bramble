# @bramble/portfolio

Token balances, the token registry, prices, NFTs and portfolio discovery.

- **Layer:** `features`. See [Modular architecture](../../../docs/MODULAR_ARCHITECTURE.md#package-responsibilities) for what each layer may depend on.
- **Entry points:** `@bramble/portfolio/nft`, `@bramble/portfolio/nft-indexer`, `@bramble/portfolio/nft-metadata`, `@bramble/portfolio/nft-token-metadata`, `@bramble/portfolio/prices`, `@bramble/portfolio/token-logos`, `@bramble/portfolio/token-registry`, `@bramble/portfolio/watched-nft`.
- **Boundary:** No presentation code or Chrome APIs.

Run `bun run check` in this directory for its type check and tests.
