# @bramble/ui-kit

Design-system primitives: skin, scale, icons, fields, controls, navigation primitives, motion constants and safe markup helpers.

- **Layer:** `presentation`. See [Modular architecture](../../../docs/MODULAR_ARCHITECTURE.md#package-responsibilities) for what each layer may depend on.
- **Entry points:** `@bramble/ui-kit/brand-mark`, `@bramble/ui-kit/catalog`, `@bramble/ui-kit/content`, `@bramble/ui-kit/controls`, `@bramble/ui-kit/dark-skin`, `@bramble/ui-kit/default-skin`, `@bramble/ui-kit/fields`, `@bramble/ui-kit/html-attributes`, `@bramble/ui-kit/icons`, `@bramble/ui-kit/navigation`, `@bramble/ui-kit/skin`, `@bramble/ui-kit/spring`, `@bramble/ui-kit/theme`, `@bramble/ui-kit/tokens`.
- **Boundary:** Cannot import persistence or feature implementations.

Run `bun run check` in this directory for its type check and tests.
