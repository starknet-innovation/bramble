# Claude Code Skills

## Project skills

- **bramble-ui-ux** — Bramble's brand, copy and UX rules for any user-visible change; a map to
  `docs/COPY_STYLE.md`, the UI Kit theme tokens and skins, and the UX docs.

## Vendored skills

These skills are vendored from [emilkowalski/skills](https://github.com/emilkowalski/skills)
(MIT license, by Emil Kowalski). They provide design-engineering and animation
guidance that Claude Code picks up automatically when working in this repo.


- **emil-design-eng** — Emil Kowalski's philosophy on UI polish, component design, animation decisions, and the invisible details that make software feel great.
- **review-animations** — Strict motion-code reviewer that checks animation code against a high craft bar (see `review-animations/STANDARDS.md`); defaults to flagging, approval is earned.
- **animation-vocabulary** — Reverse-lookup glossary that turns a vague description of a web motion effect into its exact term.
- **apple-design** — Apple's approach to fluid, physical motion (springs, gestures, momentum, interruptible transitions) translated for the web.
