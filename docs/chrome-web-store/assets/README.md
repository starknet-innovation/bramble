# Store asset sources

`icon-source.svg` and `promo-small-source.svg` are the editable, code-native sources. The PNGs are
mechanically rendered from them. Screenshots must be recaptured from the production UI template for
each store submission; never retouch transaction or account content into a screenshot.

Expected upload dimensions:

- `icon-128.png`: 128×128
- `promo-small-440x280.png`: 440×280
- `screenshot-*-1280x800.png`: 1280×800
