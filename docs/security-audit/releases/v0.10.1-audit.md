# v0.10.1 preliminary security audit and remediation

Private working report. No public disclosure or deployment is performed by this audit.

## Baseline and method

Scope: [v0.10.1-scope.md](v0.10.1-scope.md). Baseline:
`41ad4f8353c2171e7a94092968768442db8a450c`, released as v0.10.1.
Work is committed locally to `audit/v0.10.1-security`.

This is a preliminary source and regression-test audit, not a certification or a claim
that every source line has been manually reviewed. It combines entry-point enumeration,
manual tracing of selected security boundaries, deterministic adversarial tests, the
repository's complete automated gates, dependency advisory verification, packaged-browser
E2E, and artifact checks. Historical audits provide context only.

## Architecture and trust assumptions

The MV3 extension is the custody application. Untrusted website traffic crosses the
page-to-content-script bridge, then browser-authenticated runtime sender checks, then
background permissions/approval/session boundaries. The background owns vault access and
selects either the pinned Krusty signer or the Ledger queue. UI pages render permissioned
responses. The in-page provider is public code and is not a trusted authenticator.

Terminal is a separate browser application with serverless API handlers under
`apps/terminal/api`. It delegates custody to the connected wallet. Its server retains the
paymaster credential. Website/UI Lab are separate build surfaces; website deployment
uses Wrangler. None is a substitute for the background's signing authorization.

RPCs, quote APIs, discovery/prover/paymaster services, price feeds, and metadata providers
are external inputs. Pinned SDKs, deployed account/pool/executor contracts, browser storage
isolation, and Ledger firmware remain trust dependencies. Chain-id probes do not prove
that a malicious RPC reports authentic chain state. Simulation is not a promise of final
execution state. A page controlling its own origin can always deceive its own UI.

## Findings and fixes

| ID | Assessment | Finding | Remediation and evidence |
| --- | --- | --- | --- |
| V0101-01 | Low, availability | Optional analytics randomness failure could reject a privacy operation and leave its serialized queue unreleased. | `05df6142`: metadata setup is contained inside the queue's cleanup boundary; failures omit the flow identifier. Two consecutive operations succeed with a throwing randomness boundary. |
| V0101-02 | Low, privacy | Opt-out during an awaited installation-id lookup could still emit analytics metadata. | `05df6142`: recheck consent after lookup and before attaching headers. Paused-storage regression fails before the fix and passes afterward. This does not cancel a request already sent. |
| V0101-03 | Low, defensive session hardening | A delayed restore snapshot could overwrite a newer lock or unlock. | `954094ae`: bind restoration to the original generation; refuse stale reads and increment generation on restoration. Lock/replacement tests fail before and pass after. Production startup currently serializes runtime initialization behind restore, so a website-triggered exploit is not established. |
| V0101-04 | Medium, metadata confidentiality | Pending origin-grant, connected-sites, account and permission reads could outlive session revocation and return stale information. | `3caf6cab`, `bd8ee183`: check the original session after awaited reads and before returning provider metadata. Nine deterministic cases cover preferences/grant/sites reads, replacement sessions, and direct provider queries. Existing reconnect and connected-sites tests continue to pass. No unauthorized transaction or private-key disclosure was demonstrated. |
| V0101-05 | High upstream advisory; wallet-runtime exposure not established | Website tooling resolved `sharp@0.35.2`, affected by GHSA-rgj7-g3m4-5g8c. | `6e4c259e`: exact `sharp@0.35.4` override and a strict configuration assertion. Latest Wrangler still pinned the affected version at review time. Dependency audit changes from failure to success; website build and Wrangler dry run pass. Remove the override only once the parent resolves a patched version. |

The [upstream sharp advisory](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c)
affects processing untrusted image inputs and identifies 0.35.4 as patched. The observed
path is website development/deployment tooling through Wrangler and Miniflare, not the
extension package. No adversarial image was executed.

on this branch are not present in the already published v0.10.1 artifact until released.
