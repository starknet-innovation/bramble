# Translations

Bramble ships in English and Simplified Chinese (`zh-Hans`). English is the source of truth; every
other language is a catalog typed against the English keys. This page is for anyone adding or
changing a string a user reads.

## Where strings live

| What | Catalog | Rendered by |
|---|---|---|
| Wallet UI copy (screens, labels, toasts) | `packages/presentation/wallet-ui/src/i18n/messages/<area>.ts` | `t` / `th` from `i18n/messages.ts` |
| Signing-screen copy (review and confirm steps, approval cards) | `wallet-ui/src/i18n/messages/review-*.ts` | `t` / `th`, **pinned** |
| Verifier call summaries and risk flags | `packages/features/transactions/src/routing/review-messages.ts` | `reviewLine(s)`, **pinned** |
| Site warnings (phishing, lookalike, first visit) | `packages/features/permissions/src/insight-messages.ts` | `reviewLine(s)`, **pinned** |
| Error copy shown in the panel | `wallet-ui/src/i18n/error-copy-zh-*.ts`, keyed by the reviewed English | `localizeErrorCopy` (in `errorLine`, `showToast`, …) |
| Ledger device errors | `packages/platform/ledger-protocol/src/errors-i18n.ts` | `ledgerMessageIn` |
| Ledger grant tab | `apps/extension/src/ledger-grant/messages.ts` | `gt` |
| Store listing description | `apps/extension/public/_locales/<locale>/messages.json` | the browser |

The language is the `language` preference (`"auto"` follows the browser; a pinned locale wins). A
restored backup cannot set it. The side panel applies it, and `<html lang>`, before every paint.

## Adding a string

1. Add the English to the area's catalog, keyed `<area>.<screen>.<item>`, and the Chinese beside it.
   The `zh-Hans` object `satisfies Catalog<keyof typeof en>`, so a missing translation is a type
   error, and `catalogFailures` rejects mismatched placeholders, markup and padding.
2. Every fact is a `{placeholder}` filled by code: amounts, symbols, addresses, hashes, counts,
   names, network names, dates. A translation may move a fact; it may never restate one.
3. Render with `t(key, facts)` when the value goes to a UI Kit helper, `textContent` or a toast (they
   escape), and with `th(key, facts)` only when it is written straight into a string-HTML template.
   Never both. A catalog entry never contains markup; split the sentence around a tag instead.
4. Copy built at import time freezes in English. Make it a function.
5. A new area file is listed in `UI_AREA_CATALOGS` (the catalog tests refuse an unlisted file and a
   key defined by two areas).

## Signing text is pinned

Anything a user reads to decide whether to sign is pinned: the verifier's review sentences, the site
warnings, and every `review-*.ts` UI catalog. Each translation is tied to a SHA-256 prefix of the
English it was made from. When you change such an English sentence, its pin test fails and prints
the new pin; redo every translation of that sentence, then update the pin in the same change.

Background-built sentences (call summaries, risk flags, site warnings, switch and typed-data lines)
cross to the panel as references (a key plus facts) next to their English. The panel renders a
reference only when it re-renders to exactly that English, and a reference rides only when it
passes the panel's own bounds; otherwise the English is shown. Activity summaries, `data-*` values
and any string another module matches stay English: they are data.

## Not yet

- The Chinese is machine-drafted and has not been reviewed by a native speaker. The signing
  catalogs above are where a review matters most.
- Traditional Chinese browsers fall back to English rather than receiving Simplified.
- The Ledger grant tab follows the browser language, not a language pinned in Settings.
