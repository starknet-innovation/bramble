1 · Detect provider

Reads window.starknet_bramble and its get-starknet metadata (id, name, version, icon).

Expect: id bramble, name Bramble, version 0.1.0, and an inline icon.

2 · Connect

enable() → wallet_requestAccounts. First time, the wallet queues a connection request.

Expect: the call holds while the wallet shows a Connection request card; on Approve it resolves with your account address(es), on Deny it rejects. No retry needed.

3 · Authorization state

isPreauthorized() (via mc_accounts) and wallet_getPermissions.

Expect: isPreauthorized: true and permissions ["accounts"] once connected; both empty/false before connecting.

4 · Chain id

wallet_requestChainId.

Expect: 0x534e5f4d41494e on Mainnet, 0x534e5f5345504f4c4941 on Sepolia.

5 · Sign typed data (SNIP-12)

wallet_signTypedData with a well-formed SNIP-12 message.

Expect: the wallet shows a Sign request card and this call hangs until you decide. Approve → returns [r, s]; Deny → rejects with signature request denied. It must never sign without your approval.

6 · Send transaction (invoke)

wallet_addInvokeTransaction with an ERC20 transfer call (self-transfer of 1 FRI, STRK's smallest unit, by default).

Expect: the call holds while the wallet shows a Transaction request card with the decoded call. Approve → it resolves with { transaction_hash } and the tx appears in Activity; Deny → it rejects. It must never auto-submit. (On-chain success needs a deployed, funded account.)

7 · Switch chain

wallet_switchStarknetChain — only a connected origin may switch.

Expect: the call holds and the wallet shows a Network switch request — the network never changes without your approval. Approve → returns true and fires networkChanged; unconnected origins are refused.

8 · Watch asset

wallet_watchAsset (ERC20). Adds a token to the wallet's tracked list.

Expect: the call holds while the wallet shows an Add token card (with blocklist/reputation notes if any). Approve → returns true and the token appears under Tokens; malformed names are rejected.

9 · Live events

Subscribes to accountsChanged and networkChanged.

Expect: switching account or network in the wallet, or revoking this site under Connected sites, emits an event below. An unconnected origin receives nothing.
